# 19th-team1-spec

디프만 19기 1팀 기획 정본. **[PRD.md](PRD.md)가 정본**이고, 다른 문서와 다르면 이 문서에 맞춘다.

- **의견·질문**: Issues → "기획 피드백". 요구사항 ID(예: `R-02`)나 `OQ-11`을 적는다
- **수정**: `docs/` 브랜치 → PR. 웹에서는 파일의 연필 버튼 → "Propose changes"
  - 확정으로 바꿀 때는 근거(회의 날짜)를 붙인다
  - 한 번 붙인 ID는 바꾸거나 재사용하지 않는다
- **머지**: 2명 승인 후 Squash. 머지되면 디스코드로 알림이 간다
