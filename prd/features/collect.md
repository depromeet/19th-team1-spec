# C · 수집

담당: 서버 · 웹 · 화면: (피그마 링크)

## 목표

저장하는 부담을 최소로. 사용자는 링크만 넣고, 나머지는 서비스가 한다.

## 요구사항

### C-01 링크 붙여넣기 저장
상태: 확정 (11/18 회의)
- 어느 화면에서든 플로팅 버튼으로 링크 입력을 연다
- 저장할 때 분류나 메모를 요구하지 않는다
- 받는 건 링크만이다

### C-02 링크에서 정보 가져오기
상태: 논의 (OQ-04)
- 서버가 링크에서 제목·설명·사이트명·대표 이미지·본문을 가져온다
- 링크 종류별로 무엇까지 가져올 수 있는지는 개발 파트 리서치 결과로 정한다

### C-03 저장 요청과 처리 분리
상태: 확정 (11/18 회의)
- 저장 요청을 먼저 받고 뒤에서 처리한다. 처리 상태 표시는 O-04
